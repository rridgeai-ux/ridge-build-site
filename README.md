# Ridge Build contact + about site (interim)

Plain static site: upload this whole folder to any static host and point ridgebuild.co.nz at it. No build step.

- Edit `index.html` and `style.css` directly.
- Contact details appear in `index.html` (hero, contact section, call bar, schema block) and `ridge-build.vcf`.
- Fonts (Grift) and logos come from ../../branding. Check the Grift web licence before going live (website/tasks.md #22).
- The full site build in ../src and ../build is untouched and is the longer-term plan.
